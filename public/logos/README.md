# Logos des fournisseurs d'inventaire

Ces fichiers SVG sont des **marques textuelles temporaires** (placeholders) créées
maison pour la section « Connecté à votre inventaire » (`components/InventoryProviders.tsx`
et `components/fr/InventoryProviders.tsx`).

Pour utiliser les logos officiels : remplacer chaque fichier en gardant le **même nom**,
aucune modification de code n'est nécessaire.

| Fichier              | Fournisseur  |
| -------------------- | ------------ |
| `360-agency.svg`     | 360.agency   |
| `d2c-media.svg`      | D2C Media    |
| `power-go.svg`       | Power Go     |
| `edealer.svg`        | eDealer      |
| `t-advantage.svg`    | T-Advantage  |
| `nabthat.svg`        | NabThat      |

Format recommandé : SVG (ou PNG transparent 2x), logo horizontal, hauteur d'affichage 40 px.
Penser à obtenir l'autorisation d'utilisation des marques avant la mise en ligne.
